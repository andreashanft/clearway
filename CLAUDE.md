# Workflow

Stick to an ordered workflow:
* Discover: See what needs to be done and collect material, ask me if there are open questions
* Plan: Outline and plan the steps to implement
* Code: Write the code, follow best practices and aim for readable and maintainable code, write tests if applicable
* Review: Review the implementation for issues and bugs, use tools if possible like linters and formatters
* Verify: Test the result and validate it matches the planned result, if deviated on purpouse, document why
